Settings

Key Handling

Keys stay in memory by default. They are never logged, never put in URLs, and only sent to their own provider.

OpenRouter (Primary)

Models load live from GET https://openrouter.ai/api/v1/models. Model IDs are never hardcoded.

Ollama / OpenAI-Compatible Endpoint (Local)

Ollama needs OLLAMA_ORIGINS set to allow browser calls (for example OLLAMA_ORIGINS="*" ollama serve, or restrict to your host).

Direct Provider Keys (Optional)

Direct browser calls may be blocked by CORS. If that happens, the app shows a clear error telling you to use OpenRouter instead.

Cost & Limits

OpenRouter pricing comes from the live models endpoint. Free models show $0. Direct/local providers without pricing data show $0 estimate.
